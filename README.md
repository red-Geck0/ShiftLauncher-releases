# Shift Game Launcher

A controller-first game launcher for Windows handhelds. Shift brings your
installed games from Steam, Xbox / Game Pass, and other libraries into a single
big-picture interface designed for gamepad navigation.

## Features

- Unified library — Steam and Xbox / Game Pass games in one place
- Full controller navigation, built for handheld PCs
- Cover art and hero backgrounds fetched automatically
- Lightweight and fast

## Download

**Recommended:** get it from the
[Microsoft Store](https://apps.microsoft.com/detail/9PJW4XLWDJLR) — it installs
and updates automatically.

Or grab the latest installer from the [Releases](../../releases) page and run the
`.msi` file.

## System Requirements

- Windows 10 / 11 (x64)
- Steam installed for full Steam library support
- Xbox app installed for Game Pass detection
